# Projetos de Pequena Escala

Esta pasta reúne projetos de pequena escala desenvolvidos para fins de estudo e prática de conceitos específicos.

## Índice de Projetos

1. **Aproximacao_para_pi.ipynb**: Implementação de uma aproximação do valor de π utilizando o método de Monte Carlo.
2. **Spline_cubica.ipynb**: Implementação de curvas suaves compostas por polinômios de terceiro grau conectados em pontos específicos (nós).

> **Nota:** O arquivo `Spline_cubica.ipynb` contém a versão inicial do projeto com todo a lógica utilizada na construção. A pasta `Spline_cubica` contém os módulos locais e o código refatorado para seguir as melhores práticas (*pythônica*).
